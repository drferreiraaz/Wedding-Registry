## 📄 Descrição do entregável

- **Dashboard:** Visão geral do progresso, contagem regressiva e próximas missões.
- **Planejamento:** 10 fases do casamento com checklist de tarefas ponderadas.
- **Financeiro:** Controle de orçamento total, despesas e status de pagamentos.
- **Pessoas:** Gerenciamento de Convidados (RSVP), Padrinhos e Participantes da cerimônia.
- **Organização:** Cadastro de Fornecedores, Cronograma (Timeline), Nossa Casa e Lua de Mel.
- **Área Administrativa:** Sistema de login que diferencia visitantes (somente leitura) dos noivos (leitura e escrita total).

## 💻 Sobre o projeto

**Davi & Nicolly - Wedding Planner** é um aplicativo web privado e elegante criado para centralizar e facilitar o planejamento de um casamento, guiando o casal do 0% ao 100%.

O desafio proposto para este projeto era criar uma aplicação que fosse visualmente sofisticada, altamente funcional e que possuísse controle de permissões. Neste projeto, temos um sistema que diferencia **Visitantes** (que podem visualizar apenas páginas públicas como "Início", "Nosso Casamento" e "Nossa História") dos **Noivos Autenticados** (que possuem acesso total para criar, editar, excluir e fazer upload de imagens em todas as seções). Todos os dados são persistidos localmente via `localStorage`, garantindo que as informações sejam mantidas entre as sessões.

## ⚙️ Funcionalidades

- [x] Sistema de autenticação simples (Visitante vs. Noivos) com proteção de rotas e ações.
- [x] Dashboard dinâmico que calcula o progresso geral com base no peso das tarefas concluídas.
- [x] Upload de imagens (Sidebar, Vestido de Noiva e Nossa História) convertido em Base64 e salvo no localStorage.
- [x] CRUD completo para Tarefas, Convidados, Padrinhos, Participantes, Fornecedores e Despesas.
- [x] Timeline interativa (Cronograma) com reordenação de tarefas.
- [x] Interface 100% responsiva (Desktop, Tablet e Mobile) com menu lateral adaptativo.
- [x] Estados vazios (Empty States) elegantes quando nenhuma informação foi cadastrada ainda.
- [x] Botão de "Resetar Dados" para limpar o localStorage e reiniciar o planejamento.
